# Appunti · Mattoccia Labs

Official distribution packages for Appunti Studio, a local-first study workspace.

The website provides the dashboard. Media, transcripts, notes, Whisper and Qwen run on the user's computer. No cloud inference or central content archive.

Downloads, checksums and platform requirements are published together in each release. This repository contains public distribution metadata and packages only; no user data, credentials or model weights.
